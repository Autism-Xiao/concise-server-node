# 修复：demo_tmp 注册残留导致前端白屏（e2e 回滚不完全）

## 现象

前端任意页面均白屏，vite 错误覆盖层报：

```
[plugin:vite:import-analysis] Failed to resolve import "@/features/demo_tmp"
from "src/config/page-registry.ts". Does the file exist?
```

## 根因

昨天（2026-11-15 晚）可视化代码生成器 e2e 验证时，`codegen/generate` 接口把一次性模块 `demo_tmp` 真实写盘并**自动注册**进了 `page-registry.ts` / `i18n.ts` / `routeTree.gen.ts` / 路由文件。事后回滚用备份 `cp` 覆盖了 4 个文件，但**第二次 force 重新生成发生在备份覆盖之后**（时序错位），注册器又把 demo_tmp 写了回去。提交 `c4be19d` 时 `git status` 显示干净（因为残留在 HEAD 里一起提交了），遂带着残留入库：

- `src/config/page-registry.ts`：`import { DemoTmpPage }` + `'/system/demo_tmps'` 注册行
- `src/config/i18n.ts`：`nav.system.demoTmp` 中英两条

而 `src/features/demo_tmp/` 目录本体已被删干净 → import 解析失败 → **整站白屏**（page-registry 被 main.tsx 静态引用，一炸全炸）。

## 文件清单

| 文件 | 类型 | 说明 |
| --- | --- | --- |
| `src/config/page-registry.ts` | 修复 | 删除 DemoTmpPage import 与 `/system/demo_tmps` 注册行（2 行） |
| `src/config/i18n.ts` | 修复 | 删除 `nav.system.demoTmp` 中英 2 条 |

## 踩的坑

1. **回滚要落在所有写盘动作之后**：e2e 中途失败重跑时，每次 generate 都会重新执行自动注册；回滚必须放在最后一轮之后，且逐文件 `grep` 复核，不能只看 `git status` 干净（HEAD 可能本身就是脏的）。
2. **`git status` 干净 ≠ 无残留**：残留被提交进 HEAD 后 working tree 必然干净；验收要查内容而不是查状态。
3. 生成器的自动注册是「幂等追加」设计（已存在则跳过），对验证模块这种该删干净的场景，删文件不删注册就会炸。
4. 旧 vite 实例的模块缓存会让问题表象变得诡异（覆盖层可能停留在旧内容），定位时先 `rm -rf node_modules/.vite` + 重启 dev server 排除缓存干扰。

## 如何扩展 / 自检

- 以后用代码生成器做验证性生成，结束后统一执行：
  ```bash
  # 前端
  rm -rf src/features/<module> src/routes/_authenticated/system/<module>s.tsx
  grep -rn "<module>" src/config/page-registry.ts src/config/i18n.ts src/routeTree.gen.ts
  # 后端
  rm -rf src/modules/<module> src/migrations/*-Gen<Module>.ts
  grep -rn "<module>" src/app.module.ts
  ```
- 一键体检：`grep -rn "demo_tmp\|DemoTmp" src/` 应零命中。
