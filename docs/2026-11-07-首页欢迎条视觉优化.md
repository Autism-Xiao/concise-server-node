# 首页欢迎条视觉优化（2026-11-07）

## 背景

用户反馈深色主题下欢迎条「不好看」：右侧三个迷你统计（今日登录 / 在线 / 我的待办）是「裸图标 + 小字标签 + 小数字」横向挤成一团，与刷新按钮贴在一起，没有层次感，数字也不突出。

## 方案

右侧统计改为「竖分隔线分块 + 图标底座 + 大数字」排版（后台模板的常见做法）：

| 元素 | 之前 | 之后 |
| --- | --- | --- |
| 统计块分隔 | 无，仅 `gap-x-6` 空隙 | `border-l` 竖分隔线分块，块内 `px-5` 呼吸感 |
| 图标 | 裸 icon 裸放 | `size-9 rounded-lg bg-primary/10` 色块底座 |
| 数字 | `text-sm`（和标签一样大） | `text-lg font-semibold tabular-nums`（视觉主体） |
| 标签 | 在数字上方 | 移到数字下方（先看数、再看含义） |
| 头像 | 平面圆形 | 加 `ring-1` 描边 + `bg-primary/15` |
| 刷新按钮 | 与统计混在一起 | 独立 `ml-3`，统计为空时无额外间距 |

## 改动文件

| 文件 | 类型 | 说明 |
| --- | --- | --- |
| `concise-admin/src/features/dashboard/components/welcome-bar.tsx` | 修改 | 右侧统计重排（分隔线分块 / 图标底座 / 大数字下标签）、头像描边 |

数据结构（`WelcomeStat`）与权限过滤逻辑未动，纯展示层调整。

## 坑

- `CardContent` 基础类是 `flex flex-col`，外层必须显式 `flex flex-row`（沿用上一轮结论，本次重构时保留注释防止回归）。
- 刷新按钮的 `ml-3` 用条件类：统计块可能整组不出现（无权限），届时按钮不要凭空多出左边距。
