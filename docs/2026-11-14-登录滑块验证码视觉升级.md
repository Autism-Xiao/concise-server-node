# 登录滑块验证码视觉升级

日期：2026-11-14 ｜ 仓库：concise-admin（纯前端）

## 需求

后台滑动验证码模块（rc-slider-captcha）样式更优雅：原来是方角滑轨 + 白底描边滑块按钮 + 平铺浅色进度填充，观感偏旧。

## 实现（两个文件）

### `src/features/auth/login.tsx`（CSS 变量注入）

- **胶囊滑轨**：`--rcsc-control-border-radius: 999px`（轨道/滑块/进度条共用此变量，一处变三处圆）；高度 40→44px。
- **实心主题色滑块**：`--rcsc-button-bg-color: var(--primary)`、图标 `var(--primary-foreground)`，替代原来的白底描边按钮；跟随主题色切换。
- **图标换 lucide**：`tipIcon` 传入 `ChevronsRight`（默认）/ `Loader2 spin`（加载）/ `Check`（成功）/ `X`（失败），替代组件内置的裸箭头 SVG。
- 轨道底色与描边降淡（`color-mix` 半透明），减少「框中框」感。

### `src/index.css`（变量覆盖不到的细节）

- **进度填充改渐变**：`linear-gradient(90deg, primary 14% → 32% 透明)`，拖动时从滑块左侧铺开；成功/失败态跟随语义色（绿/红）做同款渐变，描边全部去掉。
- **失败抖动**：`captcha-shake` 关键帧（±3px 左右摇晃 0.4s），配合红渐变明确「没通过」。
- 滑块阴影分层（贴地 + 环境光），悬停 `brightness(1.06)` 提亮暗示可拖动。
- 提示文案 13px + 0.02em 字距。

## 约束与验证

- **320x160 出图尺寸未动**：缩放会让 x 轴校验错位（后端按原始尺寸校验）。
- tsc/eslint/prettier 全绿，测试 9/9；无头 Chrome 实测三种状态：拖动中（渐变填充跟随滑块、拼图跟随）、松手错误态（红渐变 + X 圆形按钮 + 「验证未通过」）、失败后自动刷新复位（新挑战图 + 滑块回左）。

## 踩坑

- rc-slider-captcha 的样式是运行时 `cssText` 注入，dist 里没有独立 css 文件；变量列表从 `types/index.d.ts` 的 `StyleWithVariable` 拿全（14 个 `--rcsc-*`），别漏 `--rcsc-button-hover-color`（拖动态图标色）。
- 组件的 `tipIcon` 支持换默认/加载/成功/失败四个按钮图标，但「失败过多（errors）」的提示图标在 `tipText.errors` 里，是两套配置。
- vite 后台进程被会话回收后端口号会变（5175→5174），无头脚本里的端口不能写死后不复核。

## 如何扩展

- 调滑块观感优先用 `--rcsc-*` 变量（login.tsx style 块），只有渐变/动效/阴影这类变量表达不了的才进 `.captcha-slider` 段 CSS；两处文件顶部都有注释指路。
