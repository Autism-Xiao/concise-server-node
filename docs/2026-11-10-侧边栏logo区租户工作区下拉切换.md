## 现在的形态

```
侧边栏顶部（可切换用户）          侧边栏顶部（单租户普通用户）
┌──────────────────────┐        ┌──────────────────────┐
│ 🟦 长沙示范科技…   ⌄  │        │ 🟦 Concise Admin     │
│    Concise Admin·v1  │        │    v1.0.0            │
└──────────┬───────────┘        └──────────────────────┘
           ▼ 点开下拉
           ├── 🏢 租户A · code · 永久        ✓
           ├── 🏢 租户B · code · 至 2027-01  （停用禁用）
           └── 🌐 平台视角（仅超管）
```

- 下拉点击即切换（`switchTo`，软切换快照过渡 + toast），菜单自动关闭
- 切换中触发器图标转圈、下拉底部提示「正在切换」、选项禁用防连点
- 头像菜单「切换租户」弹窗入口保留（要浏览到期时间等详情时用），两处共用 `TenantScopeProvider` 同一状态

## 每个东西是干什么的

- **`TenantWorkspace`**：唯一的「switchable 分叉」组件——内部判断 `useTenantScope().switchable`，普通用户渲染原链接（点 logo 回首页），多租户用户渲染下拉。`app-sidebar` 不需要关心分支。
- **`switchTo`**：provider 里的统一动作（接口 + localStorage + epoch 推进 + toast），返回 `boolean`；下拉菜单项点击后菜单自动关闭，无需手动处理。
- **`currentLabel`**：`null`（平台视角）时 provider 已渲染成「平台视角」，组件直接显示。

## 坑

1. **折叠模式（icon）下文字要藏**：触发器里租户名/应用名/ChevronsUpDown 都加 `group-data-[collapsible=icon]:hidden`，只剩 logo 图标，但下拉仍可点开——折叠态也能切换。
2. **`Link` 的 `as never` 类型断言别丢**：TanStack Router 对动态路径的类型检查很严，`homePath` 是运行时算出来的，直接传会报类型错（沿用原代码写法）。
3. **不可切换分支必须原样保留首页链接**：普通用户点 logo 回首页是既有习惯（`resolveHomePath()` 跟随权限防 403），换成纯展示会破坏导航。
4. **下拉宽度 64（16rem）**：超过会溢出侧边栏可视区，窄侧边栏里太宽的下拉会顶到内容区。
5. **`DropdownMenuItem` 内嵌两行文字**：外层要 `min-w-0 flex-1` + 内层 `truncate`，否则长租户名把菜单撑爆。

## 怎么扩展

- **加租户 logo/图标**：`MyTenant` 里若有 iconUrl，在下拉的 `Building2` 位置换 `img`，触发器保持系统 Logo 不动。
- **加快捷键切换**（如 `Ctrl+Shift+T` 循环切换）：在 `tenant-workspace.tsx` 里用 `useShortcutAction` 调 `switchTo` 下一个可用租户。
- **回退位置**：只动 `app-sidebar.tsx` 的 `<SidebarHeader>` 和 `site-header.tsx`，组件不依赖位置。
