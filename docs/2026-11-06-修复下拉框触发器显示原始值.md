# 修复：下拉框触发器显示原始值（如上级菜单显示 menu_35）

日期：2026-11-06　仓库：concise-admin（前端）　类型：bug 修复

## 问题现象

菜单管理的「新增/编辑菜单」对话框中，「上级菜单」触发器显示 `menu_35`（菜单 id）而不是「仪表盘」等中文名称。数据库数据本身正确，纯属前端显示问题。

## 根因

项目的 Select 是 Base UI 封装（`src/components/ui/select.tsx`），**触发器上显示的文本取自传给 `<Select>` 的 `items` 映射（value→label）**；映射缺失或为空对象时，触发器直接渲染原始 value。菜单表单里「菜单类型」「状态」都传了映射所以正常，唯独「上级菜单」传了 `items={{}}`。

| 文件 | 类型 | 说明 |
|---|---|---|
| `src/features/system/menu/components/menu-form-dialog.tsx` | 修复 | 上级菜单 Select 补 `items` 映射（`_root: '顶级'` + 全部可选父级 id→名称），新增/编辑共用同一表单，一并修复 |

未改动：`data-table/pagination.tsx` 的每页行数下拉——value 与显示文本相同（数字），无此问题。

## 怎么扩展/避免再踩

给 `<Select value={...}>` 写下拉时，**只要 value 不是给人看的文本，就必须传 `items` 映射**，否则收起状态会露出原始值（id、英文枚举、数字）。长描述类选项建议像 `MODE_LABELS`/`MODE_ITEMS` 那样拆两套：下拉里放长文案，`items` 放短标签。
