# 用户管理状态/水印列补静态圆点徽标

## 背景

截图对比：菜单管理等页的「状态」列用 `StatusBadge`（前置一个**静态圆点** + 文字），而用户管理页的「状态」「水印」两列还是手写 `<span>` 圆角标签、没有圆点。用户要求「状态静态的点，用户管理里没有需要添加上」。

## 做法

把用户管理两列统一换成全站通用的 `StatusBadge`，与其他 10+ 个页面一致（圆点默认 `pulse=false`，是静态点不闪烁）：

- **状态列**：`<StatusBadge ok={status === 1} label={meta.label} />`，label 仍取 `userStatusMap`（正常/冻结），颜色由组件统一控制（绿/红）。
- **水印列**：`<StatusBadge ok={effective} label={已开启/已关闭 + 强制标记} />`，保留「（强制开）/（强制关）」文案拼接；`watermarkEffective` 是可选布尔，先用 `=== true` 收窄成确定布尔再传给 `ok`（否则 TS2322）。

## 文件清单

### 前端（concise-admin）

| 文件 | 类型 | 说明 |
| --- | --- | --- |
| `src/features/users/index.tsx` | 修改 | 新增 `StatusBadge` import；状态列、水印列从手写 span 圆角标签改为 `StatusBadge`，补静态圆点；水印列 `watermarkEffective === true` 收窄类型 |

## 各项作用

- **视觉统一**：用户管理的状态/水印徽标与菜单、部门、岗位、字典、公告等页完全同款（静态圆点 + 圆角标签）。
- **去重**：删掉两列各自手写的 `rounded-full px-2 py-0.5 ...` 与状态/水印专属色值，颜色语义交回 `StatusBadge` 统一维护。

## 踩的坑

- **`watermarkEffective` 是 `boolean | undefined`**：直接传给 `ok: boolean` 报 TS2322。用水印是否生效的显式布尔收窄（`=== true`），标签文案与圆点颜色共用同一个收窄后的值，避免不一致。
- **强制标记要并进 label**：水印列的「（强制开）/（强制关）」不能丢，作为字符串拼在 label 后即可，圆点仍由组件渲染。

## 如何扩展

其他页面要展示「开/关」「正常/停用」这类二元状态，直接用：

```tsx
import { StatusBadge } from '@/components/status-badge'

<StatusBadge ok={enabled} label={enabled ? '正常' : '停用'} />
```

`pulse` 默认 false（静态圆点）；只有「运行中/在线/进行中」这类活状态才传 `pulse`。

验证：`npx tsc -b --noEmit`、`npx eslint`（改动文件）、`npx vite build --outDir <新目录>` 均通过。
