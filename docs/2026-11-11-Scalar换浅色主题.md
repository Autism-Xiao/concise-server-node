# Scalar 文档换浅色主题（default）

## 背景

Scalar 上线时用的是 `theme: 'saturn'`（暗紫），用户对比截图后反馈偏暗、不好看，选择换浅色主题。

## 改了什么

| 文件 | 类型 | 说明 |
| --- | --- | --- |
| `src/main.ts` | 修改 | `apiReference` 配置：`theme: 'saturn'` → `'default'`，新增 `darkMode: false` |

就两行。`/api/docs`、`/api/docs-ui`、`/api/docs-json` 三端点地址与本地自托管脚本（`/api/docs-assets/scalar.standalone.js`）均不受影响。

## 踩的坑：theme ≠ 明暗模式

第一轮只把 `saturn` 改成 `default`，截图验证**仍然是深色**。原因：

- `theme` 只定义**色板**（强调色、代码块配色等），`saturn`/`deepSpace` 本身就是暗色系色板
- 页面的**明暗初始态**由独立的 `darkMode?: boolean` 控制（`@scalar/types` 里注释：*Whether dark mode is on or off initially (light mode)*），默认会跟随浏览器 `prefers-color-scheme` —— 暗色系统用户打开仍是黑底
- 语义辨析：`forceDarkModeState: 'light'` 是**锁死**（右下角切换按钮失效），`darkMode: false` 只是初始浅色、保留用户切换能力 —— 用后者

## 验证

- `curl /api/docs`：HTML 内嵌配置出现 `"theme": "default"` + `"darkMode": false`
- 无头 Chrome 截图：白底浅灰导航、深色正文，接口树/搜索/认证面板渲染正常，外链数 0（本地自托管未被破坏）
- `npm run build` 通过（证明 `'default'` 是 `theme` 的合法取值）、eslint 0 告警

## 扩展

- 想要暗色：`darkMode: true`；想跟随系统：删掉 `darkMode` 一行
- 可选色板还有 `alternate` / `moon` / `purple` / `solarized` / `elysiajs` 等，字段仍是单行替换
