# 无列显示页面刷新按钮统一靠右

## 背景

上一轮把 14 个「有列显示」的表格页刷新按钮改成了与列显示成组靠右。本轮用户指出：菜单管理、部门管理、行政区划这 3 个页面**没有列显示按钮**，所以刷新按钮还留在原位（搜索框旁 / 标题栏按钮组中间），要求「和用户管理一致，放右侧」。

## 做法

统一采用用户管理的写法：卡片内工具栏是 `flex flex-wrap items-center gap-2`，搜索等控件在左，刷新按钮挂 `className="ms-auto"` 推到该行最右侧。这 3 个页面不加列显示按钮，只调整刷新按钮位置。

## 文件清单

### 前端（concise-admin）

| 文件 | 类型 | 说明 |
| --- | --- | --- |
| `src/features/system/menu/index.tsx` | 修改 | 搜索行（输入 / 查询 / 重置）末尾的刷新按钮补 `className="ms-auto"`，推到搜索行最右。错误态「重新加载」不动 |
| `src/features/system/dept/index.tsx` | 修改 | 刷新按钮原来在搜索框**前面**，移到搜索框**后面**并补 `ms-auto`，与用户管理同构 |
| `src/features/system/region/index.tsx` | 修改 | 刷新按钮原来在标题栏按钮组（导入 / 刷新 / 新增）**中间**，从标题栏移到卡片内工具栏末尾（筛选/展开收起按钮之后）并补 `ms-auto`，与用户管理同位置 |

## 各项作用

- **视觉统一**：全站表格页刷新按钮都靠工具栏最右；有列显示的页（14 个）是「刷新 + 列显示」成组靠右，无列显示的页（本轮 3 个 + 缓存/供应商）刷新单独靠右。
- **行政区划位置调整最大**：从页面级标题栏下移到表格卡片内的工具栏，语义上更贴近「刷新这张表格」而非「刷新整个页面」。

## 踩的坑

- **别一刀切加列显示**：用户明确这 3 页没有列显示，只让刷新靠右即可；不要为了对齐去加 `DataTableViewOptions`。
- **`ms-auto` 只作用于自身**：要推到最右就把 `ms-auto` 加在刷新按钮上（它是所在容器最后一个元素），与上一轮结论一致。

## 如何扩展

新表格页若没有列显示按钮，刷新按钮这样放即可靠右：

```tsx
<div className="flex flex-wrap items-center gap-2">
  {/* 搜索/筛选控件在左 */}
  <RefreshButton onClick={() => void reload()} className="ms-auto" />
</div>
```

验证：`npx tsc -b --noEmit`、`npx eslint`（3 个改动文件）、`npx vite build --outDir <新目录>` 均通过。
