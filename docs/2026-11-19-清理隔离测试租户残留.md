# 清理隔离测试租户残留

## 背景

用户反馈隔离测试租户 `mwkl83iy` 等还在库里。排查发现 `smoke-tenant-isolation` / `smoke-tenant-demo` 脚本建的这批租户是 `del_flag=0` 的**正常租户**，而通用清理脚本 `cleanup-smoke-data.mjs` 只删 `del_flag=1` 的软删租户，所以漏掉了。

## 残留调查

`name LIKE '隔离测试租户%'` 命中 6 个（11-17 和 11-19 各一批，每批 A/B 两个）：

| id | name | code |
| --- | --- | --- |
| 81 / 82 | 隔离测试租户mwkl83iy / Bmwkl83iy | isomwkl83iy / isobmwkl83iy |
| 105 / 106 | 隔离测试租户mwn6qw9h / Bmwn6qw9h | isomwn6qw9h / isobmwn6qw9h |
| 107 / 108 | 隔离测试租户mwn6r35l / Bmwn6r35l | isomwn6r35l / isobmwn6r35l |

关联数据（无用户关联：`sys_user_tenant`=0、`login_tenant_id`=0，删除不波及真实用户）：

- 18 个私有角色（每租户 admin/editor/viewer 三件套）
- 1032 条角色权限授权（`sys_role_permission`）
- 582 条租户套餐菜单（`sys_tenant_menu`）
- 4 条租户操作日志（`sys_log`）

## 做法

新建 `scripts/cleanup-isolation-tenants.mjs`，沿用通用清理脚本的安全惯例：

- **精确命中**：`name LIKE '隔离测试租户%' AND owner_user_id IS NULL AND id <> 1`，显式排除默认租户；demo / 正式租户命名不匹配，天然不动。
- **安全阀**：若目标租户下还有未删用户（JOIN `sys_user` del_flag=0）或有用户 `login_tenant_id` 指向它，直接中止拒绝清理。
- **级联顺序对齐后端 `TenantService.remove`**：先子后父 —— `sys_user_role` → `sys_role_permission` → `sys_role` → `sys_tenant_menu` → `sys_user_tenant` → `sys_log` → `sys_tenant`。
- 默认 dry-run，`--apply` 才删；整个清理在一个事务里，出错回滚。

凭据用 `.env` 的 `DB_PASSWORD`（通过 `SMOKE_DB_PASSWORD` 环境变量传入）——脚本内置默认值 `123456` 与实际不符，直接跑会连不上。

## 执行结果

`--apply` 实删 **1642 行**：1032 权限 + 18 角色 + 582 套餐菜单 + 4 日志 + 6 租户本身。复核预览显示"没有待清理的隔离测试租户"，剩余租户仅 3 个（默认 + 深圳/长沙 demo）。

## 踩的坑

- **正常态测试租户不在通用清理范围**：`cleanup-smoke-data.mjs` 的租户规则基于 `del_flag=1`，隔离测试租户是正常态，必须单独按命名前缀清。
- **`sys_tenant_menu` 容易漏**：套餐菜单授权有 582 条，是级联里量最大的一项；直接 `DELETE FROM sys_tenant` 会留下孤儿行。级联清单要对齐 `TenantService.remove`（该方法删 `sys_tenant_menu` / `sys_user_tenant` / `login_tenant_id` / 角色全套）。
- **安全阀先行**：删租户前务必确认 `sys_user_tenant` 与 `login_tenant_id` 无真实用户，否则会误伤正常用户的登录归属。

## 如何扩展

以后冒烟脚本若再建正常态测试租户，用统一可识别的命名前缀（如 `隔离测试租户`），本脚本即可自动覆盖。若换前缀，改脚本里 `name LIKE '隔离测试租户%'` 一处即可。

用法（记得带 `.env` 密码）：

```bash
DBPW=$(grep '^DB_PASSWORD=' .env | cut -d= -f2-)
SMOKE_DB_USER=root SMOKE_DB_PASSWORD="$DBPW" SMOKE_DB_NAME=concise_server node scripts/cleanup-isolation-tenants.mjs          # 预览
SMOKE_DB_USER=root SMOKE_DB_PASSWORD="$DBPW" SMOKE_DB_NAME=concise_server node scripts/cleanup-isolation-tenants.mjs --apply  # 执行
```
