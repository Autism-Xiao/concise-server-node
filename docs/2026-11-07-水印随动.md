# 页面水印改随动（跟随内容滚动）

## 背景

水印层原本是 `position: fixed; inset: 0` 的全屏底纹：图案钉在视口上，**页面滚动时纹样纹丝不动**，看起来像贴了一层膜浮在内容上面，滚动时长表格尤其出戏。改成「随动」：内容滚多少，底纹反向位移多少，视觉上水印像印在页面上、跟着内容一起走。

## 改动清单

| 文件 | 类型 | 说明 |
| --- | --- | --- |
| `src/components/watermark.tsx` | 修改 | 新增滚动监听 + rAF 节流的背景位移；`apply()` 记录浏览器读回值用于防篡改比对 |

纯前端改动，后端/接口/表结构均无变化。

## 实现要点

### 滚动容器是 `<main>`，不是 window

本项目布局是 `SidebarInset.h-svh.overflow-hidden` + `<main data-scroll="main" class="flex-1 overflow-y-auto">`，也就是说**页面滚动发生在 `main` 元素内部**，`window.scrollY` 永远是 0。所以监听对象是：

```ts
const scroller = document.querySelector<HTMLElement>('main[data-scroll="main"]')
```

选择器与 `tenant-scope-provider.tsx` 里取同一个容器的方式保持一致（那里用它算快照矩形），项目里 `data-scroll` 只有 `main` / `tabs` 两个，别写成 `[data-scroll="main"]` 之外的模糊匹配。拿不到容器时（登录页等没有这个 main）退回 `window` 滚动。

### 反向位移 = 图案相对内容静止

```ts
el.style.backgroundPosition = `${-scrollLeft}px ${-scrollTop}px`
```

内容向下滚 100px，背景就向上偏移 100px，平铺图案因此与内容保持相对静止。水印层仍是 `fixed -inset-0`（覆盖整个视口，含侧边栏/头部），图案无限平铺，所以位移不会露白，也不需要按文档高度撑开图层。

### rAF 节流

滚动事件按帧合并，一次滚动只写一次样式，避免连续 scroll 事件把样式写入堆成队列。

### 防篡改比对的坑

原有的 `MutationObserver` 监听 `style` 变化做防篡改恢复，而**滚动位移本身就在改 `style`**：只要拿「设置的 `url` 字符串」和「`el.style.backgroundImage` 读回值」直接比，就可能因为序列化格式差异判定为「被篡改」，于是每帧重设一次几十 KB 的 dataURL 背景图 —— 表现为滚动卡顿、水印闪。修法：

```ts
let appliedBackground = ''
const apply = () => {
  el.style.backgroundImage = url
  appliedBackground = el.style.backgroundImage // 存读回值
}
// restore 里比 appliedBackground
```

读取一次规范化后的值再比对，滚动期间比对恒定命中，不会误恢复。

## 使用与自测

水印开关、内容、样式全部仍由后端 `GET /api/v1/users/me/watermark` 下发，前端只负责绘制，**没有任何配置项新增**。

自测路径：登录后在任意长页面（用户列表、区划、日志）上下滚动 —— 水印应跟着内容一起走；左右滚动无横向滚动条时行为不变；切页签（keep-alive）后新页面滚回顶部，水印复位；侧边栏与头部区域因同属一个视口图层，纹样也会同步位移，这是全屏安全水印的预期表现。

## 扩展说明

- 想让水印只覆盖内容区（头部/侧栏不盖），就把水印层挂进 `<main>` 并改 `absolute`，但那样不再是「全屏安全水印」，是否有水印会随滚动位置变化，一般不建议
- 若将来主滚动容器换名字（`data-scroll` 改值），这里和 `tenant-scope-provider.tsx` 两处必须一起改
- 性能上背景位移只重绘视口区域，长列表滚动无压力；如果以后加大到每帧还要算其他东西，注意别把 `syncPosition` 写重
