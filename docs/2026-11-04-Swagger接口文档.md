# 变更说明：接入 Swagger 接口文档

> 日期：2026-11-04 ｜ 提交：`（本次）`

## 访问方式（服务启动后）

| 地址 | 用途 |
|---|---|
| `http://localhost:3000/api/docs` | **在线接口文档**（Swagger UI，可直接调试） |
| `http://localhost:3000/api/docs-json` | OpenAPI 3 规范 JSON（可导入 Apifox / Postman / 生成前端 SDK） |

## 改了哪些文件

| 文件 | 说明 |
|---|---|
| `src/main.ts` | 新增 Swagger 初始化：标题/版本/JWT Bearer 认证方案；挂载在 `/{globalPrefix}/docs` |
| `src/modules/user/entities/user.entity.ts` | 加 `@ApiProperty` 注解（字段说明/示例/枚举），作为响应模型展示 |
| `src/modules/user/dto/create-user.dto.ts` | 加 `@ApiProperty`：字段说明、示例值、长度/枚举约束 |
| `src/modules/user/dto/query-user.dto.ts` | 加 `@ApiPropertyOptional`（继承 PagerDto 的分页参数自动带入） |
| `src/common/dto/pager.dto.ts` | 加 `@ApiPropertyOptional`——**所有继承 PagerDto 的列表 DTO 自动获得分页文档** |
| `src/modules/user/user.controller.ts` | `@ApiTags('用户管理')` + 每个接口 `@ApiOperation` 摘要 + `@ApiOkResponse` 响应模型 |
| `src/modules/auth/controllers/auth.controller.ts` | `@ApiTags('认证')` + 接口摘要 + 登录响应绑定 `LoginResultDto` |
| `src/modules/auth/dto/login.dto.ts` | 加 `@ApiProperty` + 新增 `LoginResultDto` 响应模型 |

## 文档包含的接口（当前 6 个）

- 认证：`POST /api/auth/login`、`POST /api/auth/refresh`、`GET /api/auth/profile`
- 用户管理：`GET /api/users`（分页/搜索）、`GET /api/users/{id}`、`POST /api/users`、`PUT /api/users/{id}`、`DELETE /api/users/{id}`

## 使用要点

1. **在线调试**：打开 `/api/docs`，点右上角 **Authorize**，填入登录返回的 accessToken，即可带认证调试 profile 等接口
2. **约定**：以后每个新模块照此办理——DTO 加 `@ApiProperty`（说明+示例），Controller 加 `@ApiTags` + `@ApiOperation`，这样文档自动跟着代码走，永不过期
3. `@ApiBearerAuth('jwt')` 声明在 Controller 类上时全组接口都带锁图标
