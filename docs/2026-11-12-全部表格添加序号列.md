# 全部表格添加序号列

日期：2026-11-12
范围：前端 `concise-admin`（`7f5d0ed`）

## 一、需求

给系统里**所有数据表格**加最左侧的「序号」列。

## 二、表格分布与改法

前端表格分两类：共享的 `DataTable` 组件（TanStack Table 封装）和各页自绘的原生表格。

| 位置 | 类型 | 改法 |
| --- | --- | --- |
| `src/components/data-table/data-table.tsx` | 共享组件，覆盖用户/角色/租户/字典/公告/任务/日志等 **14 个页面** | 渲染层插入「序号」列：`pageIndex * pageSize + 行号 + 1`，**跨页续号**（第 2 页从 11 开始）；新增 `showSerial?: boolean`（默认 true）可单独关闭 |
| `src/features/system/dept/index.tsx` | 树形（拖拽排序） | `renderRows` 递归加 `counter` 参数，序号按**展开后的视觉顺序**连续递增 |
| `src/features/system/menu/index.tsx` | 树形（递归渲染） | 同上 |
| `src/features/system/region/index.tsx` | 树形（懒加载子级） | 同上；「加载下级…」提示行不占号 |
| `src/features/system/file/index.tsx` | 文件列表（list 模式） | `records.map((node, index))` 直接 `index + 1`；grid 图标模式不加 |
| `src/features/supplier/index.tsx` | 原生 `<table>` | 加 `<th>序号</th>` + `<td>{index + 1}</td>`，空态 `colSpan` 5→6 |
| `src/features/users/components/recycle-bin-dialog.tsx` | 弹窗原生表格 | 同上 |
| `src/features/users/components/user-login-log-dialog.tsx` | 弹窗原生表格 | 同上 |

样式统一：列宽 `w-14`、居中、`text-muted-foreground tabular-nums`（等宽数字翻页不抖动）。空态/提示行的 `colSpan` 全部同步 +1。
