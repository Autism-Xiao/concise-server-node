# Scalar 文档页本地自托管（告别 jsdelivr 被墙白屏）

> 起因：浏览器控制台报 `GET https://cdn.jsdelivr.net/npm/@scalar/api-reference/esm.js net::ERR_CONNECTION_CLOSED`，`/api/docs` 白屏。jsdelivr 在国内网络下经常被直接断连，上一轮文档页的 UI 脚本是走这个 CDN 的。

## 一、改了哪些文件

| 文件 | 类型 | 说明 |
| --- | --- | --- |
| `package.json` / `pnpm-lock.yaml` | 依赖 | `pnpm add @scalar/api-reference`（1.77.0，dependencies），提供浏览器端 UMD 构建产物 |
| `src/main.ts` | 修改 | 新增 `resolveScalarBundleFile()` + `registerDocsAssets()`，文档页脚本改走本地 `/api/docs-assets/scalar.standalone.js` |

## 二、原理

Scalar 渲染器（`@scalar/client-side-rendering`）有个关键行为：**`apiReference()` 只要传了 `cdn` 参数，就自动从「ESM 模块 + 懒加载 chunks」切换成「单文件 UMD + `Scalar.createApiReference`」**。UMD 是 4.8MB 的单个 `standalone.js`，无任何后续请求，最适合本地伺服：

```ts
const scalarBundle = resolveScalarBundleFile()          // 从 node_modules 定位 UMD 文件
const scalarCdn = registerDocsAssets(app, globalPrefix, scalarBundle)  // GET /api/docs-assets/scalar.standalone.js
apiReference({ ..., ...(scalarCdn ? { cdn: scalarCdn } : {}) })
```

改完后文档页 HTML 中 **`https://` 外链数量为 0**，完全离线可用（实测无头 Chrome 截图渲染正常：接口树 / 搜索 / 认证面板全部就位）。

## 三、实现要点与坑

1. **`exports` 不开放子路径**：`@scalar/api-reference` 的 `exports` 只有 `./components`、`./blocks` 等白名单，直接 `require.resolve('@scalar/api-reference/dist/browser/standalone.js')` 会抛 `ERR_PACKAGE_PATH_NOT_EXPORTED`。正确姿势是 **resolve 主入口再拼相对路径**：`path.join(path.dirname(resolve('@scalar/api-reference')), 'browser', 'standalone.js')`。
2. **`res.sendFile` 的 dotfiles 坑**：pnpm 的真实路径在 `node_modules/.pnpm/**`，send 默认把 `.pnpm` 当隐藏目录 → 直接 500。必须 `{ dotfiles: 'allow' }`（第一次部署时这个 500 很隐蔽，页面白屏但后端无异常日志，要在错误回调里把 `err.message` 打出来才看得见）。
3. **类型坑**：`app.getHttpAdapter().get(path, handler)` 的 handler 类型签名与顶层 `@types/express` 的 `Request` 不兼容（TS2345），改用 `getHttpAdapter().getInstance() as Express` 再注册，与「门面路由」的写法保持一致。
4. **不拷文件进 git**：4.8MB 的产物直接从 `node_modules` 读取，仓库不膨胀；包声明在 `dependencies`，生产 `pnpm install --prod` 也能拿到。`sendFile` 自带 ETag / Last-Modified，二次访问 304。
5. **降级路径**：包解析不到时（理论上只有依赖被裁才会发生）不传 `cdn`，渲染器回退默认 jsdelivr ESM，并打 `[docs]` 警告——不会让服务起不来。终极兜底仍是 `/api/docs-ui`（纯自托管 swagger-ui）。
6. `vue-demi` 的 postinstall 被 pnpm 忽略（`ERR_PNPM_IGNORED_BUILDS` 警告），不影响——我们只用预构建的 `dist`，不需要它的运行时编译。

## 四、实测

```
GET /api/docs                                    → 200，HTML 外链 0 个，script src="/api/docs-assets/scalar.standalone.js"
GET /api/docs-assets/scalar.standalone.js        → 200，4,930,805 字节，text/javascript，13ms
响应头                                            → Cache-Control: public, max-age=86400 + ETag（二次 304）
无头 Chrome 截图                                   → 接口树 / 搜索 / 认证面板正常渲染，零外部请求
UMD 全局                                          → window.Scalar = { createApiReference } ✓
```

## 五、怎么扩展

- **升级 Scalar**：`pnpm up @scalar/api-reference`，UMD 文件随包走，无需改代码；URL 固定但有 1 天浏览器缓存，升级后建议硬刷新。
- **想换成 ESM 分片模式**（首屏更快）：把 `@scalar/api-reference/dist/browser/` 整个目录（含 `chunks/`，约 28MB）伺服出来，`bundle: '/api/docs-assets/standalone.esm.js'` 即可；代价是要伺服 28MB 静态目录，目前没必要。
- **想给文档页加访问控制**：在 `registerDocsAssets` 与 `/api/docs` 的中间件前各加一道鉴权即可（注意 `/api/docs-assets/**` 也要一起挡，否则脚本能匿名拿到）。
