# SQL 数据目录（sql/）

## 背景

在后端仓库新建 `sql/` 目录，归档与代码迁移无关的**业务数据 SQL 文件**，当前放入行政区划全量数据。

## 改动清单

| 文件 | 类型 | 说明 |
| --- | --- | --- |
| `sql/sys_region_data_2024.sql` | 数据 | 行政区划全量数据（国家统计局 2024，44983 条：34 省 + 344 市 + 3255 区县 + 41350 镇街），`INSERT IGNORE` 按 `area_code` 去重，重复导入安全 |
| `sql/README.md` | 文档 | 目录用途、命名约定、导入命令说明 |

## 用途

- 新环境初始化时，跑完 TypeORM 迁移（建表 + 预置 34 省）后，可选执行该 SQL 一次性灌入市/县/镇街全量数据，替代走 `/v1/regions/import` 接口分批导入
- 也可用于损坏后的数据重建（先 `TRUNCATE` 再导入）

## 使用方式

```bash
export MYSQL_PWD=你的密码
"C:/Program Files/MySQL/MySQL Server 8.4/bin/mysql.exe" -uroot --default-character-set=utf8mb4 concise_server < sql/sys_region_data_2024.sql
```

## 遇到的坑

- 该文件约 5MB，此前只存在于临时目录（/tmp），有丢失风险；入库存档后可复现
- 数据生成源头脚本为 `scripts/import-region-2024.cjs`（CSV → SQL，pinyin-pro 生成拼音），两者配套使用

## 扩展说明

后续若有其它业务表需要大数据量初始化（如字典、默认菜单等），同样放到 `sql/` 下，命名 `表名_数据描述_年份.sql`，并在 `sql/README.md` 的表格里登记一行。
