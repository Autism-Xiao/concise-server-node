## 每个东西是干什么的

### 1. 权限节点穿梭框（`PUT :id/perm-nodes`）

- **语义 = 全量替换**：以提交的 `nodes` 为准 —— 新 perms 新建按钮子级（menuType=2）、未列出的既有按钮软删（del_flag=1）、交集保留（名称随提交更新）。
- **前端**：左栏「全部节点」来自 14 个标准动作（查询/添加/修改/删除/详情/状态/批量删除/添加子级/导入/导出/复制/启用/停用/重置密码），perms 由路由地址自动推导：`/system/user` + 添加 → `system:user:add`。编辑时右栏用该菜单下既有按钮子级初始化，**不带回就保存会误删**（这也是必须回显的原因）。
- **安全**：事务包裹（多步写、事务内 `manager.getRepository()`）；payload 内按 perms 去重；按钮下禁挂按钮（400）；软删后 `getPermissions`/PermsGuard 按 del_flag=0 过滤立即失效；`PermissionCacheService.invalidateAll()` 同步清缓存；role_menu 授权行不动（权限计算侧自然排除）。
- 新建菜单时前端两步走：先 `POST /menus` 拿 id，再 `PUT :id/perm-nodes`。

### 2. 打开方式（组件 / 内链 / 外链）

| 打开方式 | isRoute | internalOrExternal | 侧边栏行为 |
| --- | --- | --- | --- |
| 组件 | 1 | 0 | 正常 SPA 路由 |
| 内链 | 0 | 0 | 路由到 `/iframe?url=<路由地址>`，iframe 嵌入 |
| 外链 | 1 | 1 | `<a target="_blank">` 新窗口 |

- `/iframe` 在 `ALWAYS_ALLOWED` 白名单里（页面本身不暴露数据，协议白名单只放行 http/https，防 `javascript:` 注入）。
- 权限标识穿梭框推导前缀依赖路由地址，路由地址没填时穿梭框禁用并提示。

### 3. 列表页对齐

- 列：菜单名称（树形缩进+展开） / 菜单类型（菜单=主色标签、按钮=灰标签） / 路由地址 / 组件路径 / 权限标识 / 排序 / 状态 / 创建时间 / 操作。
- 操作列改文本按钮：`+新增`（加子级）/ `修改` / `删除`，权限位照旧 `system:menu:add|update|delete`。
- 搜索行：输入 + 查询（提交关键字） + 重置；搜索态出现「查询全部」Tab 一键还原树。

## 遇到的坑

- **穿梭框右栏必须用既有按钮子级回显**：全量替换语义下，编辑弹窗若只从标准池初始化，保存会把 `system:user:resetPwd` 这类自定义按钮误删。所以右栏初始化 = 该菜单下全部未删除按钮子级。
- **perm-nodes 主键 32 位上限**：`父id + perms 清洗` 拼接会超长，先 `.slice(0, 28)` 再拼 4 位时间片。
- **`QueryRunner`/repo 没有 hasIndex、`PUT :id` 与 `PUT :id/perm-nodes` 路由段数不同**，NestJS 不会互相吞，无需调换声明顺序。
- **冒烟断言绕接口直查库**：软删后接口列表有缓存时序风险，按钮集合断言全部走 MySQL 直查。
- 前端组件库没有 Checkbox/RadioGroup，沿用项目惯例的原生 `input[type=checkbox/radio]` + `accent-primary`。
- 3461 测试实例用 PowerShell `Get-NetTCPConnection` 按端口杀进程（Bash 里调 powershell 会被安全检查拦截，要用 PowerShell 工具）。

## 怎么扩展 / 使用

- **加标准节点**：`concise-admin/src/features/system/menu/api.ts` 的 `PERM_NODE_POOL` 追加 `{ name, action }` 即可，无需动后端。
- **接口**：`PUT /api/v1/menus/:id/perm-nodes`，body `{ nodes: [{ name, perms, sortNo? }] }`，返回 `{ added, removed, kept }`；权限位 `system:menu:update`。
- **冒烟**：起 `PORT=3461 CAPTCHA_ENABLED=false node dist/main.js`，跑 `node scripts/smoke-menu-perm-nodes.mjs`（14 项，临时数据自清理）。
