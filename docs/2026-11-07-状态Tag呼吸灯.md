# 状态 Tag 呼吸灯（2026-11-07）

## 结论先行：可以做，但不能全做

「正常 / 停用 / 启用 / 已发布」是**静态配置态**，一屏能出现几十个。全部呼吸会变成整屏闪烁噪音，反而丢掉「哪个是活的」这个信号。所以规则是：

| 状态类型 | 例子 | 圆点 | 呼吸 |
| --- | --- | --- | --- |
| 静态配置态 | 正常、停用、启用、已发布、已完成、已取消 | ✅ 安静小圆点 | ❌ |
| **活状态** | 运行中、在线、进行中 | ✅ | ✅ 柔和明暗 |

## 实现

- `src/index.css` 新增 `status-breathe` keyframes（2.4s `opacity 1 → .3 → 1`）+ `.animate-status-breathe`，并沿用项目已有的 `prefers-reduced-motion` 套路加静止兜底。**刻意不用 `animate-ping`**：那是雷达扩散圈，太抢眼，不是「呼吸」。
- `src/components/status-badge.tsx`：所有状态 tag 前置一个 `size-1.5` 圆点（颜色跟 `bg-current` 自动继承）；新增 `pulse` / `className` 两个可选参数，向后兼容现有 9 个调用点。`pulse` 时叠加 `-inset-1 blur-[3px] opacity-25` 光晕 + 核心点 `shadow-[0_0_5px_currentColor]`，两层同步呼吸。
- `src/features/ops/job/index.tsx`：定时任务「运行中」（`status === 0`）开呼吸，「已暂停」不开。
- `src/features/tasks/index.tsx`：`statusMap` 加 `pulse?: boolean`，只有「进行中」的 `CircleDashed` 图标加 `drop-shadow` + 呼吸；卡片式状态不额外套 tag。

## 怎么用 / 怎么扩展

```tsx
// 静态态（默认，不用传 pulse）
<StatusBadge ok={status === 1} label="正常" />

// 活状态：显式开呼吸
<StatusBadge ok pulse label="运行中" />
```

新页面要加呼吸灯时，先问一句「这个状态会不会实时变化」；不会就别开。若状态色不在 ok/!ok 二分里（如蓝色「进行中」），用 `className` 覆盖配色或直接用 `animate-status-breathe` 类。

## 坑

- 光晕层用 `bg-current` 而不是写死颜色，才能同时适配绿色（正常）和红色（异常）tag。
- `blur-[3px]` + `-inset-1` 的光晕会溢出 tag 边界，父容器若有 `overflow-hidden` 会被裁掉；表格 cell 一般是普通容器，没问题。
- 静态标签加圆点后宽度略增，`px-2` 不变，窄列（`w-16` 之类）需实测；本项目状态列宽足够。
- 无头 Chrome 截图看动画要加 `--virtual-time-budget=1200`，否则截到的是 0% 帧（看不出呼吸）。
