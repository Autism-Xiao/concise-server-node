# 仪表盘移动端适配（横向溢出修复）

## 问题

窄屏（手机竖屏 / 模拟器）下，仪表盘「登录趋势」图表以及它下面的整块内容超出视口右侧，主内容区出现横向滚动条。

## 根因

1. **grid 轨道被 SVG 撑爆**：`index.tsx` 的双列布局 `grid xl:grid-cols-3`，grid 轨道默认 `min-width: auto`。recharts 的 `<svg>` 按容器**测量的像素宽度**渲染，容器变窄的一瞬间（手机竖屏、侧边栏收起、窗口缩小），旧宽度的 SVG 成为列项的 min-content，轨道无法收缩 → 整列（图表 + 图下面的最近操作卡片）一起超宽。
2. **主滚动容器只有纵向约束**：`_authenticated.tsx` 的 `<main>` 是 `overflow-y-auto`，横向溢出直接变成横向滚动条；内边距 `p-6` 对手机也偏大。

## 修复（均为前端 concise-admin）

| 文件 | 改动 |
| --- | --- |
| `src/features/dashboard/index.tsx` | 双列 grid 与两个列项加 `min-w-0`，切断「SVG min-content → 轨道」的撑爆链；skeleton 同步 |
| `src/features/dashboard/components/login-trend-chart.tsx` | 图表容器加 `min-w-0 overflow-hidden`（先裁住旧宽度 SVG，ResponsiveContainer 的 ResizeObserver 随即按真实宽度重画）+ `debounce=50`；高度改 `h-48 sm:h-56`（小屏矮一点省空间） |
| `src/routes/_authenticated.tsx` | `<main>` 加 `min-w-0 overflow-x-hidden`，内边距 `p-4 sm:p-6`（移动端小内边距，全站受益） |

## 坑

- JSX 注释 `{/* */}` 不能放在三元表达式的分支位置（那里必须是单个表达式），会报 `TS1005: ')' expected`；要写在元素内部或用行注释。
- `overflow-hidden` 不改变盒子自身的 min-content 计算，真正断链的是 grid 列项上的 `min-w-0`；`overflow-hidden` 只负责把重画前的旧 SVG 裁住、避免闪现横向滚动。
- 修复后不要在别的页面依赖「main 横向滚动」来查看宽表格——宽表格应各自包 `overflow-x-auto` 容器。

## 验证

前端 `tsc` / `eslint` / `vite build` 全绿。视觉验证需在手机或 DevTools 设备模拟下滚动仪表盘确认不再横向滚动。
