# 快捷键设置收进系统设置页

## 需求

快捷键改绑原来藏在「偏好设置抽屉」（config-drawer）里，入口深；用户要求放到「系统设置」页统一管理。

## 改了哪些文件

| 文件 | 类型 | 说明 |
| --- | --- | --- |
| `concise-admin/src/components/shortcut-settings.tsx` → `src/features/settings/shortcuts/shortcut-settings.tsx` | 移动 | 录制/改绑组件原样迁入 settings 功能目录（git mv，无内容改动） |
| `concise-admin/src/features/settings/shortcuts/index.tsx` | 新增 | 「快捷键」设置页：Card 包裹 + 说明文案，风格与 display/notifications 页一致 |

| `concise-admin/src/components/config-drawer.tsx` | 修改 | 移除快捷键 section 与对应 import |

## 每个东西是干什么的

- **页面组件**：复用原 `ShortcutSettings`（录制态监听 window 捕获阶段按键，Esc 取消 / Backspace 清绑 / 冲突拒绝），只是外壳从抽屉 section 换成 Card 页。
- **权限**：`/settings` 前缀在 `lib/permissions.ts` 的 `ALWAYS_ALLOWED` 里，新子页无需任何权限登记，所有登录用户可见。
- **存储**：快捷键绑定仍在 localStorage（`lib/shortcuts`），与抽屉时代同一份，**原有改绑结果无缝保留**。

## 遇到的坑

- page-registry 的 settings 页用 `label`（纯中文），业务页用 `titleKey`（i18n 键）——照 settings 段既有写法用 `label`，别混。
- vite 没起的话 `routeTree.gen.ts` 不会自动更新，tsc 会报 route 不存在；确认 vite 在跑后它自己重生成（本次 10 处命中）。

## 怎么扩展 / 使用

- 访问：登录后「系统设置 → 快捷键」（或直接开 `/settings/shortcuts`）；偏好抽屉里不再有该区。
- 以后加新快捷键：在 `lib/shortcuts` 的 `SHORTCUT_IDS`/`SHORTCUT_LABEL_KEYS` 注册，本页自动多一行，无需改页面。
