# 个人水印收进系统设置页

## 需求

个人水印（自己账号的开关/内容/密度）原来藏在头部「偏好设置」抽屉的界面设置区里，位置突兀、信息架构混乱。收进「系统设置」独立子页，抽屉回归纯外观面板。

## 改了哪些文件

| 文件 | 类型 | 说明 |
| --- | --- | --- |
| `concise-admin/src/features/settings/my-watermark/index.tsx` | 新增 | 「我的水印」设置页：开关/内容/密度 + 锁定原因提示 + 生效优先级说明 |
| `concise-admin/src/routes/_authenticated/settings/my-watermark.tsx` | 新增 | 路由 `/settings/my-watermark` |
| `concise-admin/src/config/page-registry.ts` | 修改 | 登记页面（label「我的水印」、Stamp 图标、settings: true）+ import |
| `concise-admin/src/features/settings/index.tsx` | 修改 | 设置页左侧导航加「我的水印」项（快捷键与水印策略之间） |
| `concise-admin/src/components/config-drawer.tsx` | 修改 | 移除水印区及全部相关状态（wm/wmContent/wmError/applyWatermark/wmLocked/effectiveDensity、WATERMARK_DENSITIES 常量、useWatermark/Input/WatermarkDensity import） |

## 每个东西是干什么的

- **页面**：复用 `useWatermark()` 上下文（`WatermarkProvider` 挂在 `_authenticated`，设置页可直接用），逻辑与原抽屉一致——开关即时保存（PUT /v1/users/me/watermark）、内容失焦保存（留空=跟随全局）、密度三档切换、被管理员锁定时置灰并显示原因文案。
- **文案复用 i18n 键**：`config.watermark` / `watermarkContentPlaceholder` / `watermarkContentHint`（含 {username} 等占位符说明）/ `watermarkDensity` / `density.*`，从抽屉平移过来继续用，中英双语不受影响。
- **信息架构**（收敛后）：

```
系统设置：个人资料/账户/外观/通知/显示/快捷键/我的水印（个人）/水印策略（管理员，全站）
偏好抽屉：主题/字号/主题色/圆角/语言/灰度/色弱——纯视觉，不再掺水印
```

## 遇到的坑

- 清理 `WATERMARK_DENSITIES` 常量时用了一次占位替换，差点把 `DIRECTIONS` 常量复制成重复声明——大段删除后必须 grep 验证一遍再提交。
- 密度按钮文案一开始写死了中文，抽屉原实现走 `t(labelKey)` 支持英文——迁移时别丢 i18n。

## 怎么扩展 / 使用

- 访问：登录后「系统设置 → 我的水印」（`/settings/my-watermark`），所有登录用户可见（`/settings` 前缀在 ALWAYS_ALLOWED）。
- 与「水印策略」页的分工：我的水印=个人开关/内容/密度；水印策略=管理员的全站模式与样式参数；锁定时个人页只读并显示原因。
