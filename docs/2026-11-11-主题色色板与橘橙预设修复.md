# 主题色两处修复：色板明暗不一致 + 橘橙预设冷调中性色（2026-11-11）

## 用户反馈

1. 「主题色抽屉和设置下，第一个颜色不一致」
2. 「第二个橘橙显示的颜色怎么不对」

## 排查过程（无头浏览器实测）

用 Playwright 注入 admin token 截图「外观设置页」与「偏好抽屉」四个状态（深/浅 × 两处 UI）：

- 深色模式下，设置页第 1 个圆点（默认）是**近黑色**，暗背景上几乎看不见；抽屉里是**近白色**（`swatchDark` 生效）→ 反馈 1 实锤
- 点「橘橙」后读 `--primary` = `oklch(0.64 0.17 36.44)` 与色板一致，主色确实是橙；但**侧边栏选中项高亮是蓝色** → 反馈 2 实锤

## 根因

### 1. 色板明暗不一致

偏好抽屉 `config-drawer.tsx` 的色板有深色模式处理（`swatchDark ?? swatch` + `border border-black/10 dark:border-white/20`），而外观设置页 `appearance/index.tsx` 直接 `backgroundColor: color.swatch`，没有跟随明暗模式。「默认」是唯一有 `swatchDark` 的预设（浅色下近黑、深色下近白），所以只有第 1 个圆点两处不一致。

### 2. 橘橙预设中性色是冷调

脚本对比全部 12 套预设的 OKLCH 色相：**只有橘橙**的主色是 36°（橙），而 accent 244°、muted 248°、背景 237° 全是冷蓝调——明显是从某个蓝色预设复制后只改了主色。其余 11 套（含同为暖色的落日/琥珀）中性色都跟随主色色相。选中橘橙后：主色橙，但侧边栏选中项（sidebar-accent）、悬停（accent）、图表（chart-1~5 除 chart-2 外）都是蓝。

## 改动清单

| 文件 | 类型 | 说明 |
| --- | --- | --- |
| `src/lib/theme-presets.ts` | 改 | 重写 `tangerine` 预设 light/dark 全套变量：背景/前景/卡片/secondary/muted/accent/border/input/图表/侧边栏全部改为暖色相（35~65°，参照落日配方但更柔和），primary/ring/sidebar-primary 保持 `oklch(0.64 0.17 36.44)` 不变（色板与实际应用继续一致） |
| `src/features/settings/appearance/index.tsx` | 改 | 色板补上 `swatchDark` 明暗跟随逻辑 + `border border-black/10 dark:border-white/20` 边框 + 勾选图标颜色随底色（黑底白勾/白底黑勾），与偏好抽屉完全一致；自定义彩虹圈也补了边框 |

## 遇到的坑

1. **编辑 theme-presets.ts 时旧 dark 块残留**：一次 Edit 的 old_string 只覆盖到 `dark: {` 开头，new_string 却给了完整新预设，导致旧 dark 内容裸露在数组里成为语法碎片 —— 编辑后必须回读文件确认结构完整（这次回读发现并清掉了）。
2. **诊断用了无头浏览器**：滑块验证码没有明文 debug（原 CAPTCHA_DEBUG 已随 svg-captcha 下线），改为用 `.env` 的 JWT_SECRET 手签 `{ id, username }` token 注入 localStorage 绕过登录（`isSessionInvalid` 只查黑名单，白板 token 有效）。截图脚本放在仓库内临时文件，跑完删除。
3. **测试会污染用户偏好**：点色板的操作经 `pushSettings` 落了云端（admin 的 themeColor 被测试改成橘橙），验证完要点回「森林」还原 —— 测试脚本最后必须恢复现场。

## 验证

- `tsc -b` 无错误、ESLint 干净、前端 7/7 测试通过
- 截图复验（深色模式）：设置页第 1 个圆点变近白、与抽屉一致；选橘橙后侧边栏选中项/悬停/图表全部为暖橙调，`--primary` 与色板值一致
- 测试后已把 admin 的主题色恢复为森林（`oklch(0.65 0.14 145)`）

## 扩展/使用

- 以后**新增主题预设必须让中性色相跟随主色**：background/foreground/card/muted/accent/border/chart/sidebar 系列的 OKLCH 色相取主色附近（暖色 20~75°、冷色同色相），只换 primary 会复现这次的「选了橘橙高亮是蓝」。
- 色板若在深色模式下需要不同展示色（如默认色），记得给预设加 `swatchDark`；两处色板 UI（config-drawer 与 appearance）逻辑已对齐，改一处时同步另一处。
