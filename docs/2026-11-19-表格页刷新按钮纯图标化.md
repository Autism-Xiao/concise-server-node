# 表格页统一添加纯图标刷新按钮

## 背景

截图反馈：菜单管理页操作列改图标后，希望所有表格页工具栏也都有一个刷新按钮，且**只留图标不留汉字**（如「🔄」）。非表格页（概览、服务监控、开放平台等）的刷新按钮按用户确认保持原样。

## 各项作用

- **统一组件**：所有表格页的刷新按钮样式、尺寸、交互一致（outline 方形图标按钮），避免各页手写导致样式漂移。
- **纯图标 + 中文语义**：按钮只渲染 `RefreshCw` 图标；中文放 `title`（鼠标悬浮提示）和 `aria-label`（屏幕阅读器）。字典页用 `title="刷新字典类型/刷新字典项"` 区分两个按钮。
- **接对各页刷新函数**：`useServerTable` 页接 `reload()`（保留当前关键字/筛选/分页），手写分页页接 `load()`/`refresh()`；能拿到 loading 状态的页面传 `disabled`/`spinning`。

## 踩的坑

- **非表格页不动**：按用户确认，概览、服务监控、开放平台等非表格页的「🔄 刷新」文字按钮保持原样，本轮只改表格页。
- **文件管理页本就是纯图标**：`system/file` 的刷新按钮已是 `size="icon"` + `sr-only` 文本，符合规范，无需重复改造。
- **错误态按钮不算刷新按钮**：如在线用户「重试」、列表错误态「重试」，那是错误恢复入口，保留文字，不改成图标。
- **清理未用 import**：换掉旧按钮后，`RefreshCw` 在若干页面变成未使用 import，eslint 会报错，需一并删除。

## 如何扩展

新表格页直接 `import { RefreshButton } from '@/components/ui/refresh-button'`，放在工具栏按钮组里：

```tsx
<RefreshButton onClick={() => void reload()} />
// 有 loading 态时：
<RefreshButton onClick={load} disabled={loading} spinning={loading} />
// 需要区分文案时：
<RefreshButton onClick={fn} title="刷新字典项" />
```

验证：`npx tsc -b`、`npx eslint`（全部改动目录）、`npx vite build` 均通过。
