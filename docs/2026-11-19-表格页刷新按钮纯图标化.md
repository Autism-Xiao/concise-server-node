# 表格页统一添加纯图标刷新按钮

## 背景

截图反馈：菜单管理页操作列改图标后，希望所有表格页工具栏也都有一个刷新按钮，且**只留图标不留汉字**（如「🔄」）。非表格页（概览、服务监控、开放平台等）的刷新按钮按用户确认保持原样。

## 各项作用

- **统一组件**：所有表格页的刷新按钮样式、尺寸、交互一致（outline 方形图标按钮），避免各页手写导致样式漂移。
- **纯图标 + 中文语义**：按钮只渲染 `RefreshCw` 图标；中文放 `title`（鼠标悬浮提示）和 `aria-label`（屏幕阅读器）。字典页用 `title="刷新字典类型/刷新字典项"` 区分两个按钮。
- **接对各页刷新函数**：`useServerTable` 页接 `reload()`（保留当前关键字/筛选/分页），手写分页页接 `load()`/`refresh()`；能拿到 loading 状态的页面传 `disabled`/`spinning`。

## 踩的坑

- **非表格页不动**：按用户确认，概览、服务监控、开放平台等非表格页的「🔄 刷新」文字按钮保持原样，本轮只改表格页。
- **文件管理页本就是纯图标**：`system/file` 的刷新按钮已是 `size="icon"` + `sr-only` 文本，符合规范，无需重复改造。
- **错误态按钮不算刷新按钮**：如在线用户「重试」、列表错误态「重试」，那是错误恢复入口，保留文字，不改成图标。
- **清理未用 import**：换掉旧按钮后，`RefreshCw` 在若干页面变成未使用 import，eslint 会报错，需一并删除。

## 位置调整（追加）

后续要求「放到列显示的旁边」：把有 `DataTableViewOptions`（列显示）的 14 个表格页，刷新按钮从工具栏开头/标题栏移到**列显示按钮左侧**，两个一起靠右相邻。

- ~~`DataTableViewOptions` 自带 `ms-auto` 把自己推到最右，刷新按钮放它左边即自动跟随靠右，无需再加 `ms-auto`。~~ **此结论已于同日修正**：`ms-auto` 只挂在列显示按钮自身，只会把它一个元素推到最右，位于其左侧的刷新按钮仍留在搜索框旁（截图实锤）。最终改为把 `ms-auto` 从 `DataTableViewOptions` 移到 `RefreshButton` 上，让「刷新 + 列显示」成组靠右。详见 [刷新按钮与列显示成组靠右](./2026-11-19-刷新按钮与列显示成组靠右.md)。
- `RefreshButton` 默认尺寸从 `size="icon"`（size-9）改为 `size="icon-sm"`（size-8），与列显示按钮的 `h-8` 对齐。
- 无列显示按钮的 5 页（缓存/供应商/部门/菜单/行政区划）刷新按钮保持原位置不动。
- 字典页只移动「刷新字典项」（右列表，紧邻列显示），左列表「刷新字典类型」保持原位。
- 字段变更日志标题栏右侧按钮容器移空后，外层 `justify-between` 简化为普通标题块。

## 如何扩展

新表格页直接 `import { RefreshButton } from '@/components/ui/refresh-button'`，放在工具栏按钮组里；**有列显示按钮时放它左侧**：

```tsx
<RefreshButton onClick={() => void reload()} className="ms-auto" />
<DataTableViewOptions table={table} columnLabels={columnLabels} />
// 有 loading 态时：
<RefreshButton onClick={load} disabled={loading} spinning={loading} className="ms-auto" />
// 需要区分文案时：
<RefreshButton onClick={fn} title="刷新字典项" className="ms-auto" />
```

验证：`npx tsc -b`、`npx eslint`（全部改动目录）、`npx vite build` 均通过。
