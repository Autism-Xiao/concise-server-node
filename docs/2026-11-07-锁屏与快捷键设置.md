# 锁屏功能 + 全局快捷键设置（前后端）

## 功能一：锁屏

离开工位时把工作区整体锁住，输入当前账号密码才能回到操作中的页面（页签、表单状态都保留）。

### 后端（concise-server-node）

| 文件 | 类型 | 说明 |
| --- | --- | --- |
| `src/modules/auth/dto/verify-password.dto.ts` | 新增 | `VerifyPasswordDto`：password 6~64 位 |
| `src/modules/auth/services/auth.service.ts` | 修改 | 新增 `verifyPassword(username, password)`；把「密码失败计数 + 达标锁一天」抽成 `countPasswordFailure()` 与登录共用 |
| `src/modules/auth/controllers/auth.v1.controller.ts` | 修改 | 新增 `POST /v1/auth/verify-password`（登录态，限流 20 次/5 分钟/IP） |
| `scripts/smoke-test.cjs` | 修改 | 新增 10.6 节 3 项用例；水印 whitelist 用例改读全局值断言（原硬编码 14 被库内数据漂移打穿） |

关键设计：
- **失败与登录共享锁定计数**：verify-password 连错 5 次同样触发「锁一天」（code 1009），否则拿到已解锁设备的人可以绕过登录锁定无限试密码。校验通过则清零计数
- **业务失败用 HTTP 400 而不是 401**：前端 `getApiResult` 把 401 统一按「登录过期」处理会强制登出，密码错误若返回 401 会把人直接踢回登录页
- 校验无副作用：不改令牌、不踢会话，只回答「密码对不对」

收录的快捷键：

| 动作 | 默认组合 | 来源 |
| --- | --- | --- |
| 命令面板 / 全局搜索 | Ctrl+J | 既有 |
| 折叠 / 展开侧边栏 | Ctrl+B | 既有（原硬编码在 sidebar.tsx） |

匹配规则：Ctrl 同时接受 `e.ctrlKey` 或 `e.metaKey`（Mac ⌘ 等效），与项目既有行为一致；改绑必须含 Ctrl/Alt/⌘ 修饰键，防止纯字母键吞掉正常输入。

## 遇到的坑

1. **401 会触发前端强制登出**：`getApiResult` 把 HTTP 401 一律当「登录过期」，verify-password 的密码错误改用 HTTP 400（code 仍是 1007）
2. **冒烟用例被数据漂移打穿**：水印 whitelist 用例硬编码 `fontSize===14`，库里全局值已是 12，误报失败；改成先 `GET /v1/system/watermark` 取当前值再断言
3. **ESLint react-hooks/refs**：Provider 的 value 不能挂在 ref 上在渲染期改写，改回 `useMemo` + 稳定回调
4. **录制快捷键要拦在调度中心之前**：设置界面用 `window.addEventListener('keydown', fn, true)` 捕获阶段 + `stopPropagation`

## 扩展方式

- **新加快捷键**：`SHORTCUT_DEFAULTS` 加默认值 → `SHORTCUT_LABEL_KEYS` 与 i18n 加文案 → 组件里 `useShortcutAction(id, handler)`，设置界面自动出现该行
- **自动锁屏**（空闲 N 分钟）：可在 `LockProvider` 里加 idle 计时器，调 `lock()` 即可
