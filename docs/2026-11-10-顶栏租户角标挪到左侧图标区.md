# 顶栏租户角标挪到左侧图标区（前端布局调整）

> 仓库：`concise-admin`（提交 `605dfbb`）
> 时间：2026-11-10
> 后端：无改动

## 背景

租户切换器经历三轮位置调整：

1. **顶栏（搜索框左侧）**：常驻可见，但与搜索、铃铛、头像挤在同一侧，右侧图标已有 9 个；
2. **头像下拉菜单**：用户选定，但当前租户被藏起来，需要点头像才知道自己在哪个租户；
3. **顶栏左 + 头像菜单双入口**：补了 `TenantBadge` 角标，位置在搜索框左边；
4. **本轮**：用户要求把角标放到**最左侧图标区**（侧边栏折叠按钮旁）。

## 改动文件

| 文件 | 类型 | 说明 |
|---|---|---|
| `src/components/layout/site-header.tsx` | 修改 | `TenantBadge` 从 `<Search />` 之前挪到 `<SidebarTrigger />` 之后；分隔线从「折叠按钮后」移到「角标后」，`mr-2` 改 `mx-1`，让分隔线左右都有间距 |
| `src/features/system/tenant/components/tenant-badge.tsx` | 修改 | 宽度 `max-w-44` → `max-w-40` 并加 `shrink-0`；租户名文字改 `hidden truncate sm:inline`（窄屏只留图标）；注释更新为新位置的理由 |

## 改完的顶栏结构

```
[☰ 折叠]  [🏢 当前租户名 ⌄]  │  [面包屑]  …空白…  [搜索] [全屏] [主题] [语言] [配置] [提醒铃] [消息铃] [头像]
```

- 角标和折叠按钮同属「导航控制」区，语义一致
- 右侧只剩功能图标（加一个搜索框），拥挤问题缓解
- 面包屑仍紧跟分隔线，层级没变

## 每个东西是干什么的

- **`TenantBadge`**：只读展示当前租户名（`useTenantScope().currentLabel`）+ 一次点击打开 `TenantSwitchDialog`
- **`switchable`**：`tenant-scope-provider` 算出来的开关，单租户且非超管时为 `false`，角标整体 `return null` —— 普通用户顶栏左侧和原来完全一样
- **`switching`**：切换中把图标换成转圈并禁用按钮，防止连点
- **头像菜单里的「切换租户」入口保留**：两个入口共用同一份 context 状态，切换后同时刷新

## 坑

1. **窄屏会挤掉面包屑**：角标带文字时最宽 160px，和面包屑同一行，手机端会把「用户管理」压没。所以文字用 `hidden sm:inline`，窄屏只显示 🏢 图标（点击行为不变）。
2. **`shrink-0` 不能漏**：flex 容器空间不足时按钮会被压扁成几个像素，点击区域消失。
3. **分隔线位置决定分组语义**：放「折叠按钮后」= 分隔「折叠按钮 / 租户 + 面包屑」；放「角标后」= 分隔「导航控制 / 面包屑」。后者更符合视觉分组，改时注意 `mx-1`（`mr-2` 会让左侧没间距、紧贴角标）。
4. **角标不要放进 `flex-1` 右侧**：右侧是「工具区」（搜索、通知、设置），租户是「上下文」，混在一起会让人误以为是设置项。

## 怎么扩展

- **想加租户到期/环境标识**（如「试用还剩 3 天」）：在 `tenant-badge.tsx` 的 `<span>` 后加一个 `Badge`，数据从 `useTenantScope()` 取；不要新开接口，`/v1/tenants/mine` 已返回 `expireAt`。
- **想让某个位置显示但不可点**（如只看不切）：把 `Button` 换成 `div`，保留 `currentLabel`，不要复制一份状态。
- **新增顶栏元素**：只加在 `<Search />` 之后（工具区），不要再往左侧导航控制区塞，左侧只保留「折叠 + 租户」两件。
- **位置想回退**：只改 `site-header.tsx` 里 `<TenantBadge />` 那一行的位置即可，组件本身不依赖位置。
