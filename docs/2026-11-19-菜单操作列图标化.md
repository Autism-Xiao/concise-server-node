# 菜单管理操作列改为纯图标按钮

## 背景

菜单管理页（`features/system/menu`）操作列的「新增 / 修改 / 删除」三个按钮带汉字，列宽被文字撑开，在固定右侧操作列的表格里比较占地方。改为只保留图标，文字移到 `title` / `aria-label`（悬浮仍能看到含义，屏幕阅读器也保留语义）。

## 文件清单

| 文件 | 类型 | 说明 |
| --- | --- | --- |
| `src/features/system/menu/index.tsx` | 修改 | 操作列三个按钮由 `variant="ghost" size="sm"` + 文字，改为 `variant="ghost" size="icon" className="size-7"`，补 `title` / `aria-label`，移除按钮内的汉字 |

## 各项作用

- `size="icon"` + `size-7`：正方形图标按钮，与系统里岗位/租户/任务页的图标按钮尺寸一致。
- `title`：鼠标悬浮显示中文含义（替代被移除的按钮文字）。
- `aria-label`：保留无障碍语义，图标按钮没有可读文本时屏幕阅读器靠它识别。
- 权限判断（`hasPermission('system:menu:add' / update / delete)`）和点击行为（`openCreate` / `openEdit` / `setDeleting`）均未改动。

## 踩的坑

- 只删文字不换 `size` 会留下 `px-1.5 gap-0.5` 的横向内边距，图标不居中；必须同时换成 `size="icon"` + `size-7`。
- 纯图标按钮一定补 `title` 和 `aria-label`，否则鼠标悬浮没提示、无障碍检查不通过。

## 如何扩展

其它页面若也要图标化操作列，照搬 `size="icon" className="size-7" title="..." aria-label="..."` 四件套即可；危险操作（删除）保留 `text-destructive hover:text-destructive` 配色。

验证：`npx tsc -b` 与 `npx eslint src/features/system/menu/index.tsx` 均通过。
