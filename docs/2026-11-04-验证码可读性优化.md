# 2026-11-04 验证码可读性优化

## 背景

验证码 `noise: 3`（3 条干扰线）+ `color: true`（每个字符随机彩色），叠加后字符被亮黄绿/蓝/粉等颜色打散，肉眼很难辨认。

## 根因（svg-captcha 源码行为）

`node_modules/svg-captcha/lib/index.js:55`：

```js
if (bg) {
  options.color = true
}
```

**只要传了 `background`，`color` 就被强制置 `true`**——所以此前即使显式传 `color: false` 也没用，字符永远是随机彩色。另外 `color: false` 的默认行为也不是深色文字，而是随机灰度，必须后处理。

## 改动文件

| 文件 | 类型 | 说明 |
|---|---|---|
| `src/modules/auth/services/captcha.service.ts` | 修改 | 干扰线 3→1；去掉 `color`/`background` 参数；生成后正则后处理统一配色（字符深灰、干扰线浅灰） |

## 完整代码

```ts
const { text, data: rawSvg } = svgCaptcha.create({
  size: 4,
  ignoreChars: 'il1O0o',
  // 可读性优先：只 1 条干扰线；不传 background（svg-captcha 只要传背景就强制 color:true 字符随机彩色）
  noise: 1,
  width: 132,
  height: 44,
  fontSize: 56
})
// 后处理统一配色：字符深灰、干扰线浅灰（fill="none" 的干扰线 path 不动）
const svg = rawSvg.replace(/fill="(?!none)[^"]*"/g, 'fill="#3d4a57"').replace(/stroke="[^"]*"/g, 'stroke="#c3ccd6"')
```

## 实测

接口返回的 SVG 中颜色集合收敛为：

```text
fill:   #3d4a57（4 个字符 path，深灰蓝）+ none（干扰线）
stroke: #c3ccd6（干扰线，浅灰）
```

4 位字符全部同色深色显示，仅 1 条浅灰干扰线，宽 132 / 高 44 / 字号 56，辨识度大幅提升。

## 遇到的坑

1. **`background` 与 `color` 的隐藏联动**：svg-captcha 传了背景色就强制 `color: true`，文档没写明；想要「浅色背景 + 深色统一文字」只能不传背景、生成后自己改 fill。
2. **干扰线 path 的 `fill="none"` 不能被误替换**：正则用负向先行 `fill="(?!none)[^"]*"` 排除，否则干扰线会被填充成色块。
3. **字符 path 与干扰线 path 在输出里是随机排序的**（`sort(() => Math.random() - 0.5)`），不能按顺序区分，只能按属性特征（fill vs stroke）替换。

## 怎么扩展 / 使用

- 想调颜色：改两个十六进制值即可（`#3d4a57` 字符色、`#c3ccd6` 干扰线色）。
- 想更简单/更难：调 `noise`（0 = 无干扰线，2 = 两条）与 `fontSize`；`ignoreChars` 已剔除易混淆的 `il1O0o`。
- 想要背景色：在前端容器上给 CSS 背景即可，不要传给 svg-captcha。
