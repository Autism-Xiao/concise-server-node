# 用户管理：导入 / 导出接口与 Excel 报表样式

> 2026-11-05 · 后端 `concise-server-node` + 前端 `concise-admin`

给用户管理补上导入导出，并把导出的 Excel 从「能用」提升到「能直接发给业务方」：
头部有大标题与副标题（导出时间 / 操作人 / 条数 / 筛选条件），表头深蓝底白字并冻结，数据区斑马纹 + 细边框 + 列宽按内容自适应，底部有说明行。
这套样式落在 `utils/xlsx.util.ts`，所以**角色、登录日志、操作日志的导出一起变好看了**，无需各自实现。

## 二、接口

| 方法 | 路径 | 权限编码 | 说明 |
|---|---|---|---|
| GET | `/api/v1/users/export?keyword=&status=&deptId=` | `system:user:export` | 导出 .xlsx，与列表同过滤条件、不分页，单次最多 5000 行 |
| GET | `/api/v1/users/import-template` | `system:user:import` | 下载导入模板：sheet1 = 说明 + 表头，sheet2 = 填写示例 |
| POST | `/api/v1/users/import` | `system:user:import` | multipart，字段名 `file`；支持 .xlsx（推荐）与 .csv(UTF-8)；≤5MB、≤2000 行；写操作进操作日志 |

路由顺序有讲究：`export` / `import-template` 必须声明在 `GET /v1/users/:id` 之前，否则会被当成 id 去查用户。

**导出列**：`登录账号, 真实姓名, 手机号, 邮箱, 性别, 状态, 角色, 所属部门, 工号, 创建时间`
密码与密码盐永不导出；角色、部门多个时用 ` / ` 连接；状态列正常绿底、冻结红底。

**导入列**（表头别名容错，`*` 与空格会被忽略）：

| 列 | 必填 | 说明 |
|---|---|---|
| 登录账号 | 是 | 3~100 位、字母开头，允许字母/数字/下划线/点/横线/@；**已存在则更新该用户** |
| 真实姓名 | 是 | 最长 100 |
| 密码 | 否 | 6~64 位；新建留空用 `123456`，更新留空表示不改密码 |
| 手机号 / 邮箱 | 否 | 邮箱格式校验 |
| 性别 | 否 | 男 / 女 / 未知 |
| 生日 | 否 | `1990-01-01`，也认 `1990/1/1`、`1990.1.1` |
| 工号 | 否 | 唯一 |
| 所属部门 | 否 | 部门名称，多个用 `/` `,` `、` `;` 分隔，**第一个为主部门** |
| 角色 | 否 | 角色名称或角色编码，多个同上分隔 |
| 状态 | 否 | 正常 / 冻结（也认 1 / 2） |

**导入返回**：

```json
{
  "total": 4,
  "created": 1,
  "updated": 0,
  "skipped": 0,
  "failed": 3,
  "errors": [
    { "row": 10, "username": "importtest02", "message": "部门不存在：不存在的部门（请填部门名称，或先到部门管理里创建）" },
    { "row": 11, "username": "1bad", "message": "登录账号需 3~100 位、以字母开头…" }
  ]
}
```

- `row` 是 **Excel 里的真实行号**（模板有 7 行头部，数据从第 9 行开始，报错就是第 9/10/11 行），不用自己数
- 单行失败不阻断其他行；失败行**不写库**（先校验后写入，不会出现「用户建了但部门没绑上」）
- 部门/角色写错直接判该行失败，不静默丢弃——避免「导入成功但权限没了」
- 同一份文件内账号重复：第二次出现记 `skipped`

## 三、Excel 长什么样

```
┌──────────────────────────────────────────────────────────────┐
│ 用户列表                                        ← 18pt 加粗，浅蓝底 │
│ 导出时间：2026-11-05 19:05:56 · 操作人：admin · 共 128 条记录          │
├──────────┬────────┬─────────┬──────────┬────┬────┬───────────┤
│ 登录账号  │ 真名   │ 手机号   │ 邮箱      │性别│状态│ 角色 ...  │ ← 深蓝底白字，冻结
├──────────┼────────┼─────────┼──────────┼────┼────┼───────────┤
│ admin    │ 管理员  │ 1861...│ ...      │ 男 │正常│ 管理员    │ ← 白底
│ zhangsan │ 张三   │ 1342...│ ...      │未知│冻结│ 访客      │ ← 浅蓝斑马纹
└──────────┴────────┴─────────┴──────────┴────┴────┴───────────┘
  说明：密码与密码盐不导出；角色、部门有多个时用「/」分隔，部门顺序即主次。
```

细节：

- 标题/副标题合并整行，`mergeCells` 后写入；副标题随筛选条件变化（带 `筛选：关键字=admin`）
- 冻结 `ySplit=4`（有标题时表头在第 4 行），滚动时标题+表头常驻
- `showGridLines: false`：关掉 Excel 默认网格线，只留自己画的细边框
- 列宽：`width` 显式优先；否则按表头与内容算（中文记 2 个字符宽），夹在 8~46 之间
- 单元格超 5000 字符截断加省略号（Excel 上限 32767，日志的长请求参数可能超）
- 打印：列数 > 6 自动横向、`fitToWidth=1`、`printTitlesRow` 让每页都带表头
- 模板的必填列表头加黄色 `*`（richText，不动单元格文本），列说明写成单元格批注（鼠标移上去能看到）

## 四、踩过的坑

1. **模板表头带 `*` 导致定位失败**：模板里必填列表头是 richText（`登录账号` + ` *`），`cell.text` 读出来是「登录账号 *」，用 `headerKeys` 严格等值匹配找不到表头 → 导入直接报「未找到「登录账号」列」。修法：定位前把表头的空格、`*`、`＊` 全部剔掉再比。
2. **行号对不上**：一开始按「表头行 + 数组下标」算行号，模板有 7 行头部时用户看到的行号会偏 7 行。改成 `readXlsxTable` 一并返回 `headerRow`（`eachRow` 回调自带真实行号），后续行号全用真实值。
3. **重复的用户按钮权限**：`menu_7/8/9` 已是用户新增/修改/删除，新补时误建了 `menu_72/73/74`，授权树里出现两个「用户新增」。已删掉重复行，seed 只保留 `menu_75/76`。**加按钮前先在 `sys_permission` 里按 `perms` 查一遍**。
4. **全角空格被 lint 拦**：副标题原来用 `　·　` 分隔，`no-irregular-whitespace` 直接报错，改半角空格 + `·`。
5. **中文文件名**：只给 `filename="用户列表.xlsx"` 时部分浏览器下载成乱码，补 `filename*=UTF-8''${encodeURIComponent(name)}`，前端优先解析这一段。
6. **老调用方兼容**：`buildXlsx` 的 `title` 是第 4 个可选参数，不传就退化为「表头 + 数据」（只是样式变好看），`readXlsxRows` 签名不变——角色的 CSV/xlsx 导入逻辑一行没改。

## 五、怎么扩展

**新增一个导出**（任意模块）：

```ts
const buffer = await buildXlsx(
  '订单列表',
  [{ header: '订单号', width: 24 }, { header: '金额', align: 'right' }, { header: '状态', align: 'center' }],
  rows, // 二维数组，数字保持数字类型（Excel 可直接求和）
  {
    title: '订单列表',
    subtitle: `导出时间：${formatDateTime(new Date())} · 共 ${rows.length} 条记录`,
    notes: ['说明：金额单位为元。'],
    cellStyle: (_row, col, value) => (col === 2 && value === '已取消' ? { fontColor: 'FFB42318', fillColor: 'FFFDECEC' } : undefined)
  }
)
```

**新增一个导入**：

1. 模板：`buildImportTemplateXlsx({ sheetName, title, notes, columns, samples })`，`required: true` 会自动加星号，`hint` 变批注
2. 解析：`readXlsxTable(buffer, { headerKeys: ['登录账号', '账号'] })` 拿到 `{ rows, headerRow }`
3. 业务：参照 `UserService.importUsers` —— 先建别名表定位列 → 批量预载关联数据（角色/部门）→ 逐行校验+写库 → 汇总 `{ total, created, updated, skipped, failed, errors }`

**只想改配色**：`xlsx.util.ts` 顶部 `PALETTE`（titleBg/brand/zebra/border）一处改，全站导出跟着变。
