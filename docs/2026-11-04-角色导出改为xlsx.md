# 角色导入导出改回 Excel（.xlsx）

> 2026-11-04 · 上一轮导出给的是 CSV，这一轮按「导出应该是 .xlsx」改成真正的 Excel 工作簿

## 一、为什么改

上一轮为了少装依赖走了 CSV（与日志导出统一）。但对角色这种「导出给业务同事编辑再导回」的场景，CSV 的体验问题很实在：

- 双击 CSV 在 Excel 里是导入向导，中文列宽全挤在一起
- 编码稍有不对就是一片乱码（上一轮只能靠 `\uFFFD` 检测拦截）
- 没有任何格式：表头不区分、不能冻结、不能筛选

改成 `.xlsx` 后：单工作簿单工作表，表头加粗 + 浅灰底 + 冻结首行 + 自动筛选 + 预设列宽，双击就是规整表格；导入也直接吃 `.xlsx`，不再担心编码。

## 四、实现要点

**`buildXlsx`**

```ts
const sheet = workbook.addWorksheet('角色', { views: [{ state: 'frozen', ySplit: 1 }] })
sheet.columns = [{ header: '角色名称', width: 20 }, ...]
sheet.autoFilter = { from: { row: 1, column: 1 }, to: { row: 1, column: columns.length } }
return Buffer.from(await workbook.xlsx.writeBuffer())
```

- 冻结首行用 `views[0].ySplit=1`，不是 `sheet.views` 直接赋新数组（会覆盖掉默认视图配置）
- 数字按数字写（`已授权菜单数` 是 number），Excel 里能直接求和；`null/undefined` 统一转空串
- `autoFilter` 只在有数据行时设置，空表设置会产生一个悬空筛选按钮

**`readXlsxRows`**

- 用 `cell.text` 取「显示值」：日期、数字、公式结果都能拿到可读文本，不用自己判断 cell.type
- 列数取 `max(sheet.columnCount, row.cellCount)`，避免某些行比表头短时数组错位
- 丢弃整行空白（Excel 常见的尾部空行），保证 `rowNumber` 与用户在 Excel 里看到的行号一致

## 五、遇到的坑

**1. `exceljs` 安装时 pnpm 报 `ERR_PNPM_IGNORED_BUILDS`**
`@scarf/scarf` 的安装脚本被 pnpm 拦了（只是统计脚本，不影响功能），包已经装好，可忽略。

**2. `workbook.xlsx.load()` 的入参类型**
Node 的 `Buffer` 与 exceljs 声明的 `ArrayBuffer` 不兼容，需要 `buffer as unknown as ArrayBuffer`；运行期没问题（Buffer 是 Uint8Array 子类，exceljs 内部按 binary 处理）。

**3. 顺手修掉的旧问题：新建角色没有创建时间**
`BaseService.create` 不会自动写 `createTime`（项目里都是 service 显式 `createTime: new Date()`，只有公告实体用了 `@CreateDateColumn`）。角色模块之前漏了这行，导致列表「创建时间」显示 `-`、导出该列为空。已在 `createRole` 和导入的新建分支补上。**存量角色不受影响**，之前导出的空值就是这个原因。

**4. 路由顺序仍然要注意**
`GET /roles/export`、`GET /roles/import-template` 必须声明在 `@Get(':id')` 之前，改格式时不要调整顺序。

## 六、验证

- `GET /export` → 200，`magic: PK`（xlsx zip 头），size ≈ 7KB，文件名 `roles-<ts>.xlsx`
- `GET /import-template` → 200，读回内容：`[['角色名称','角色编码','描述'],['运营专员','operator','…'],['财务审核','finance_auditor','']]`
- 用 `buildXlsx` 造 4 行文件上传 → `{total:4, created:3, failed:1}`，非法编码 `2bad` 报在第 5 行（与 Excel 行号一致，第 1 行是表头）
- 导出 `?keyword=xlsx_test` 读回：描述里的逗号、引号、中文标点完整保留；`创建时间` 已有值（`2026-11-04 19:53:38`）
- `.csv` 仍可导入（兼容老文件）；`.txt` 返回 400「仅支持 .xlsx（推荐）或 .csv 文件」
- 前后端 tsc / eslint / oxlint 全绿
