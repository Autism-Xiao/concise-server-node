**关键坑（下次必看）**：
- Windows 下 `mysql -N -e "SHOW TABLES"` 输出带 `\r`，直接循环 DROP 会报 `ERROR 1103 Incorrect table name`，必须 `| tr -d '\r'`
- `role` / `menu` / `role_menus` 互相外键引用，单独 DROP 报 `ERROR 3730`；要在**同一会话**里 `SET FOREIGN_KEY_CHECKS=0; DROP ...; SET FOREIGN_KEY_CHECKS=1;`（每次 mysql 调用是独立会话，分号必须写在一起）
- mysqldump/mysql 不在 PATH，完整路径 `C:\Program Files\MySQL\MySQL Server 8.4\bin\`，且需 `MSYS_NO_PATHCONV=1` 防止路径被 Git Bash 转换
