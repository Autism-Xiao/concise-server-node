## 会话过期先弹确认框（concise-admin）

用户反馈：登录超时页面闪一下直接回登录页。改法：`lib/http.ts` 的 `handleUnauthorized()` 只 logout + `notifySessionExpired()`，新组件 `SessionExpiredDialog`（挂 `__root`）弹「登录已过期」，点「重新登录」才 `location.assign('/login')`。去重靠 `lib/session-expired.ts` 的模块级 `notified` 标记（并发在途请求同时 401 只弹一个框），复位在重新登录点击后。弹框不可关（受控 Dialog 忽略 onOpenChange）。

**坑**：① 本项目 Dialog 是 Base UI（`@base-ui/react`），不是 Radix——没有 `onEscapeKeyDown`/`onPointerDownOutside`，也没有 `dismissible`；受控组件忽略 `onOpenChange` 就是防关的正确写法。② 单跑 `npx tsc --noEmit` 会假绿（与 `tsc -b` 检查口径不同），以后以 `npm run build`（`tsc -b && vite build`）为准。③ i18n 走 `config/i18n.ts` 平铺字典 + `useLocale().t`，新增 `session.expired.*` 三键（中英都要加）。

## 多维度代码体检（结论未落地修复，挂账）

四个方向（开放平台/鉴权、认证与邮件、数据层与多租户、前端）审查 + 逐条回源码复核，基线：单测 10/10、tsc 0 错。P0 12 条中最重的：
- **跨租户用户接管链**：`UserService.findOne` 覆写丢租户条件（user.service.ts:747），update/delete/resetPassword/setStatus/批量三处（In(ids) 无租户）全部可按 id 跨租户写，`UpdateUserDto` 还能直接传 password。
- **写路径租户条件含 tenant_id=0**：`tenantRawCondition` 的 `OR tenant_id = 0` 被 BaseService.update/delete 沿用 → 租户可改删平台共享行。
- **/v1/open/** 人类令牌直通**：ApiScopeGuard 对 `!isApp` 直接放行 + open 控制器无 @Perms 无租户过滤 → 任意登录账号拉全平台用户。
- **app/webhook findOne 无租户**：跨租户重置密钥拿明文 / 改删订阅（IDOR）。
- **Webhook dispatch 无 tenant_id**：A 租户用户事件（含 realname）推给 B 租户回调。
- **SSRF**：回调地址只查 `startsWith('https://')`，fetch 默认跟重定向。
- **改密/重置密码后 refresh 仍有效 7 天**：refresh 只查 token 级黑名单不查用户级 revoke；reset-by-code 完全不 kick 会话。
- **前端 2 小时硬踢**：JWT 2h/refresh 7d，前端全仓无续签逻辑，401 即登出。
- **Webhook secret 前端拿不到**（后端列表明文返回但页面不渲染）+ reset 按钮权限码错（前端 `system:app:update`，后端 `system:app:reset`）。
- **2FA 重绑无需密码**（setup 直接覆盖 secret）、**邮箱可自助改 → forgot 链路接管账号**、**滑块验证码答案空间 141 个（±5 容差）且 verify 无独立限流**。

P1 集中在「先查后写」非原子（验证码消费/失败计数/refresh 轮换/备份码/设置 PUT）与若干功能缺陷（pageSize 无上限、supplier 物理删、notice 单条无租户、customer 空串撞唯一键、ER_DUP_ENTRY 未统一转 400、投递流水无清理、user.updated 声明未派发）。用户尚未指示修复排期。

## 审计 P0 修复（12 条全部落地，双仓库推送）

- **租户写路径**：新增 `tenantWriteCondition()`（BaseService.update/delete 用，共享行只有平台能写）；`UserService.findOne` 走 `applyTenantToUsers`（EXISTS 查 sys_user_tenant）——**sys_user 无 tenant_id 列**，按 business 表套路写 where.tenantId 会编译报错；批量 find 改 `findWritableByIds`；batchAssignRoles 补角色租户边界。
- **开放平台**：ApiScopeGuard 人类令牌 403；jwt.strategy app 分支带 tenantId；open 接口按应用租户过滤；app/webhook findOne 补租户（防跨租户重置密钥拿明文）；dispatch 带 `opts.tenantId`（事件归属租户）只发同租户/平台订阅；SSRF 三层校验（assertPublicCallbackUrl：协议/IP 段/DNS）+ fetch redirect:'manual'。
- **会话吊销**：online.service 新增 `isUserRevokedSince()`，refreshToken() 校验用户级吊销标记；changePassword 全量下线（不再 keepToken——keepToken 路径其他端 refreshToken 能续命 7 天）；password-reset 重置后 forceOffline。**吊销标记按秒对齐**，同秒内登录→改密→重放刻意放行（脚本冒烟复现过这个"假失效"，加 1.2s 间隔实测 2101 拒绝生效）。
- **2FA/邮箱**：totp.service 注入 UserService，setup/deactivate 密码二次确认（新 DTO two-factor-password.dto.ts）；updateMyProfile 改邮箱验证密码（防被盗 token 走 forgot 链路接管）；前端 2FA 卡片改两步式（密码→二维码→动态码）、profile 页改邮箱显示密码框、改密成功后 logout+跳登录。
- **前端静默续签**：http.ts 401 先单飞 refresh 并重放（allowRefresh=false 防循环），失败才走会话过期弹框；测试沙箱必须补 `AbortSignal` 全局（缺了会 ReferenceError 被 catch 吞成 null，续签测试假失败）。
- **验证码**：TOLERANCE 5→3（中奖率 7.3%→4.6%），verify 独立限流 30/min（v1+旧版两个控制器）；webhook secret 前端展示+复制，reset 按钮权限码 system:app:update→system:app:reset。
- **坑**：mysql2 默认 FOUND_ROWS（update 相同值 affected=1，BaseService 404 检查安全）；/open/token 是 @RawResponse 裸 OAuth 体（冒烟脚本按统一包装解析会假 401）；改密端点 PUT 不是 POST；本会话审批多次超时且有一次"被拦"脚本实际执行成功——敏感操作结果必须只读探针复核。
- 冒烟后已清理：冒烟应用/订阅删除，admin 密码还原 admin123 并复核，3461 实例已停。遗留 P1 见 docs/2026-11-17-审计P0修复.md。
