## 会话过期先弹确认框（concise-admin）

用户反馈：登录超时页面闪一下直接回登录页。改法：`lib/http.ts` 的 `handleUnauthorized()` 只 logout + `notifySessionExpired()`，新组件 `SessionExpiredDialog`（挂 `__root`）弹「登录已过期」，点「重新登录」才 `location.assign('/login')`。去重靠 `lib/session-expired.ts` 的模块级 `notified` 标记（并发在途请求同时 401 只弹一个框），复位在重新登录点击后。弹框不可关（受控 Dialog 忽略 onOpenChange）。

**坑**：① 本项目 Dialog 是 Base UI（`@base-ui/react`），不是 Radix——没有 `onEscapeKeyDown`/`onPointerDownOutside`，也没有 `dismissible`；受控组件忽略 `onOpenChange` 就是防关的正确写法。② 单跑 `npx tsc --noEmit` 会假绿（与 `tsc -b` 检查口径不同），以后以 `npm run build`（`tsc -b && vite build`）为准。③ i18n 走 `config/i18n.ts` 平铺字典 + `useLocale().t`，新增 `session.expired.*` 三键（中英都要加）。

## 租户唯一键改造（对照多租户方案文章的差距修复）

文章核对结论：ALS 上下文/中间件/读写分离/异步传租户/前端 Header 全已实现且部分更严，唯一差距是「唯一索引必须包含 tenant_id」。落地：
- **迁移 1794820000000-TenantUniqueKeys**（幂等 hasIndex）：sys_dict `uk_sd_dict_code`、sys_position `uk_sys_position_code`、sys_level `uk_sys_level_name`、sys_depart `uniq_depart_org_code` 四个全局唯一键 → `(tenant_id, code)` 联合唯一。原全局唯一更严，存量数据必满足新约束，ADD UNIQUE 不会失败。**config/sys_user/tenant/region 不动**（前者刻意平台级、用户无 tenant_id 列、平台数据全局唯一正确）。
- **统一口径**：DB 联合唯一 = 同租户内不重码、租户间可重码；应用层查重（applyTenantScope）= 本租户 ∪ tenant_id=0 共享行内唯一 → **不许撞平台内置编码**（DB 层表达不了这条，只能应用层管）。
- **service 配套**（与 P0 同源的漏网）：dict.service findActive/updateDict/deleteDict、dict-item 详情/updateItem/deleteItem 原来不带租户条件直写（知道 id 就能改平台字典）→ 读走 applyTenantScope、写加 tenantWriteCondition、命中不了按 404；dict/post/level 三处导入原来 `find()` 全表 + 按 code 全局匹配更新（隐性跨租户写入口）→ 匹配收进租户可见范围 + 命中共享行报「与平台内置 XX 冲突」；dict 导入的字典项 manager.save 不走 BaseService，**显式补 tenantId 打标**；dept 的 org_code 占用检查统一收进 isOrgCodeTaken（生成链路本来就租户感知）；listByCode 按编码取字典补租户范围（联合唯一允许重码后，不加范围撞码取哪条全凭运气）。
- **实测**（3461 免验证码实例）：跨租户重码 ✓、同租户拒绝 ✓、租户撞共享编码 5101 ✓、租户读只见自己+共享 ✓、平台视角创建正常 ✓；build/单测 10/10 绿；探针数据已清理。

- **前端静默续签**：http.ts 401 先单飞 refresh 并重放（allowRefresh=false 防循环），失败才走会话过期弹框；测试沙箱必须补 `AbortSignal` 全局（缺了会 ReferenceError 被 catch 吞成 null，续签测试假失败）。
