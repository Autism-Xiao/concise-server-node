## 锁屏启动闪屏修复
- 用户反馈：开启锁屏后关页面重开，短暂闪一下工作区再切锁屏。
- 根因：前端 `lock-provider.tsx` 首帧 `useState(isLocked)` 读 sessionStorage，关标签页/浏览器重开时被清空 → locked=false 先渲染工作区，异步 `/auth/lock-state` 返回 true 才切锁屏，时间差即闪屏。服务端状态源+本地镜像的设计没变，缺的是首帧遮罩。
- 修法（前端 concise-admin）：加 `checking` 态 + 启动 effect 的 `.finally` 结束（失败 fail-open 不卡遮罩）；渲染层 `pendingVerify = checking && !locked` 时才盖同款全屏遮罩（`fixed inset-0 z-[100] bg-background/80 backdrop-blur-md` + Loader2 转圈），盖住 children 而非卸载；**本地已锁路径不加遮罩**，避免"转圈→锁屏"二次闪。
- 验证：tsc/eslint/prettier/vite build 全绿。坑：遮罩务必只在 `checking && !locked` 加；`.finally` 要判 `cancelled`；用 aria-hidden 标记纯视觉遮罩。
- 提交：前端 `5d3dd81`、后端文档 `5ccec11`，均已推送。文档 docs/2026-11-21-锁屏启动闪屏修复.md + README 登记。
- **前端无 docs 目录**：所有变更文档统一写后端仓库 `docs/`（历次前端改动都这样），前端代码单独提交推送。
