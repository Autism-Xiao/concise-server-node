## 操作日志改为同步写入（消除 @nestjs/observe unfinished span warn）

- 现象：每次写请求打 warn「Trace xxx (/api/v1/auth/logout) was reported without LogService#recordOper / Repository#save / INSERT sys_log, had not ended 1000ms after the operation did」
- 根因：oper-log.interceptor 用 tap + void this.logService.recordOper(...) 的 fire-and-forget，HTTP 响应先返回，INSERT 在 trace 收尾后才跑，span 无归属；进程此时退出还会丢日志
- 改法：成功路径 concatMap(async data => { await recordOper({status:0}); return data })，失败路径 catchError → from(recordOper({status:1})).pipe(mergeMap(() => throwError(() => error))) 保持原异常
- 坑：throwError 在 rxjs 7+ 从 'rxjs' 导出，写 'rxjs/operators' 会 TS2305；日志写入别用 mergeMap（并发发起不保序）
- 顺带：resolveErrorMessage 从 error.getResponse().message 取文案（数组用「；」拼），失败日志从「Bad Request Exception」变成「用户名长度须在 3~100 位之间；username must be a string；…」
- 验证：logout 201 / 34ms，响应返回时 sys_log 已能查到；空 body 建用户仍 400 + code 1001；服务日志再无 warn
