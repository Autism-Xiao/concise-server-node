## 修复：前端报 Unexpected end of JSON input（实际是代理端口错配）

- 现象：5174 打开 concise-admin，所有接口失败，提示 `Failed to execute 'json' on 'Response': Unexpected end of JSON input`。
- 根因两层：① `concise-admin/vite.config.ts` 的 `BACKEND_URL` 默认 `127.0.0.1:3000`，后端 `.env` 是 `PORT=3459`，代理返回 502 + text/plain；② 前端 `getApiResult` 裸 `res.json()`，把「后端连不上」掩盖成 JSON 解析错误。
- 不是 500 的原因：请求没到后端，代理转发阶段就失败；后端 AllExceptionsFilter 对业务异常/HTTP 异常/未知异常都返回 JSON，只要进到后端就不会出现这个错。
- 改动：vite 默认端口改 3459（支持 BACKEND_PORT 覆盖）；http.ts 新增 `parseJsonBody` 按空响应/非 JSON/502·503·504/解析失败分别提示；download.ts 先读 text 再解析；测试补 headers/text 与两个网关错误用例。
- 本地排查坑：① 系统 `http_proxy=127.0.0.1:61096` 会劫持 curl，必须加 `--noproxy '*'`；② vite 只监听 `[::1]:5174`，用 IPv4 访问连不上；③ 用 Windows 独立进程方式启动后端会因代理变量大小写重名失败，且进程会被会话回收——改用后台任务方式启动最稳。
- 服务现状：后端 3459（Node 24，D:\programs\nodejs，后台任务运行）与前端 5174 均在跑；验证码 200、未带验证码登录 code=417、无 token 401 全部正常。
